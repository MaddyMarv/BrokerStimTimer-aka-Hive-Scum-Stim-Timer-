### [Broker Stim Timer (Hive Scum Stim Timer)](https://www.nexusmods.com/warhammer40kdarktide/mods/654)
<img width="650" height="701" alt="image" src="https://github.com/user-attachments/assets/29d02989-caf0-49c3-a4be-a2cd8754ba12" />

Moveable on-screen timer for Broker stim duration and cooldown.

**Options:**

**General**
- Track Standard Stims
- Font Size & Icon Size
- Show Decimals
- Link All Positions
- Shared Icon & Text Position X/Y

**Ready**
- Ready Color
- Ready Icon Position X/Y
- Show Ready Icon

**Active**
- Active Color
- Active Icon & Text Position X/Y
- Show Active Icon & Timer

**Cooldown**
- Cooldown Color
- Cooldown Icon & Text Position X/Y
- Show Cooldown Icon & Timer
